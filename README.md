# Basic Chatbot

A simple rule-based chatbot built in Python as part of my CodeAlpha Python Programming Internship.

## About

The chatbot reads what the user types and replies with a predefined answer. It keeps chatting in a loop until the user says "bye".

## Features

- Replies to predefined inputs such as "hello", "how are you" and "bye"
- Not case-sensitive, so "Hello" and "HELLO" both work
- Includes extra replies for "what is your name" and "help"
- Gives a friendly fallback reply for anything it doesn't understand
- Console-only, with no graphics or audio

## Concepts Used

- `if-elif` statements
- Functions
- Loops
- Input/output

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```
python chatbot.py
```

## Sample Output

```
Chatbot: Hello! Let's chat. (Type 'bye' to exit)
You: hello
Chatbot: Hi!
You: how are you
Chatbot: I'm fine, thanks!
You: bye
Chatbot: Goodbye!
```
